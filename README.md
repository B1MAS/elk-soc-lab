# ELK SOC Lab

**Elasticsearch, Logstash и Kibana в Docker Compose** для практики SOC. Готовый набор синтетических событий позволяет пройти путь от исходного журнала до фильтра в Kibana.

```text
samples/events.jsonl → Logstash → Elasticsearch → Kibana Discover
```

Учебный стенд для сбора и разбора журналов. Logstash читает три вымышленных события, Elasticsearch индексирует их, Kibana показывает результат.

Нужен Docker с Compose v2. Запуск: `docker compose up -d`. Проверка: `docker compose ps` и `docker compose logs logstash`.

Kibana слушает только 127.0.0.1:5601 на сервере. Для доступа с основного ПК используй SSH с личным ключом: `ssh -N -L 127.0.0.1:5601:127.0.0.1:5601 USER@SERVER`. Затем открой http://127.0.0.1:5601. Не пробрасывай порты на роутере. Elasticsearch и Logstash не публикуют порты. В этой учебной конфигурации вход в Elastic отключён, поэтому держи стенд на личном хосте или изолированной VM. Любой с доступом к серверу или Docker может получить доступ к данным.

В Kibana создай Data View `soc-lab-*` без фильтра по времени, открой Discover и проверь три события. Запрос `event.outcome: failure` должен оставить два. Зафиксируй запрос, наблюдение и вывод. Тестовые данные синтетические.

Статус: конфигурация подготовлена, запуск и результат проверки ещё не подтверждены. Для портфолио добавь результат после запуска. Публикуй только код, синтетические данные и обезличенные скриншоты.

## Проверка и остановка

`sh scripts/verify.sh` ждёт индексации и проверяет, что из трёх событий два относятся к неудачному входу. Если доступ к Docker требует администратора, запусти `sudo sh scripts/verify.sh`.

`docker compose down` останавливает контейнеры и сохраняет индекс в томе.
